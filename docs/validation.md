# 검증 기록

2026-09-16 작성. 실제 API 키와 사용자 사진은 사용하지 않았습니다.

## 실행 환경

- Linux, Python 3.12.14
- 빈 가상환경에 `requirements-dev.txt`로 설치
- Flask 3.1.3, Pillow 12.3.0, ReportLab 4.5.1, python-dotenv 1.2.3, pytest 9.1.1
- Windows와 macOS용 실행 명령은 README에 제공하며, 두 운영체제에서 직접 실행한 결과는 아닙니다.

## 확인한 내용

- 자동 테스트 14개 통과: 가입, 로그인 유지, 주제별 저장, 사진, 발행, 내보내기, 계정 간 접근 구분, CSRF, 삭제·복원, 발행본 보존, 중복 요청, 수정 충돌, 공유 범위·해제, 긴 기사, 출력 이스케이프, AI 어댑터 성공·실패.
- 동기 테스트 설정과 별개로 실제 작업 스레드에서 발행 완료 후 결과 화면 HTTP 200 확인.
- PNG 크기 1080×1920과 한글·일러스트 배치를 직접 확인.
- PDF를 이미지로 렌더링해 확인. 긴 본문이 여러 페이지로 이어져도 각 기사의 끝 표식이 남는지 텍스트 추출로 확인.
- JavaScript 구문 검사와 Python의 정의되지 않은 이름·사용하지 않는 값 검사 통과.

## 확인 범위의 한계

- OpenAI 어댑터는 모의 공급자 응답으로 검증했습니다. 유료 실요청은 실행하지 않았습니다.
- 날씨 API의 실시간 응답은 검증하지 않았으며, 기본 설정은 미연동입니다.
- 테스트 환경의 브라우저가 로컬 주소 접근을 차단해 웹 화면의 실제 브라우저 자동화 검증은 완료하지 못했습니다. HTTP 화면 응답과 서버 기능, 출력 파일을 확인했습니다.
- 모바일 실기기의 촬영·시스템 공유·Instagram 연결은 기기별 확인이 필요합니다. 기능 미지원 시 안내와 파일 다운로드 경로를 제공합니다.
