# 디자인 에셋

## 일러스트

`app/static/art/stationery.png`는 이 프로젝트를 위해 이미지 생성 도구로 새로 만든 3×3 투명 배경 에셋 시트입니다. 레퍼런스 사이트의 그림이나 로고를 복사한 파일은 포함하지 않습니다.

아트 방향: 빈티지 문구, 얇은 잉크 선과 수채화, 크림색 종이와 어울리는 더스티 블루·버터 옐로·작은 레드 포인트, 사랑스럽고 장난스러운 분위기. UI의 글자는 이미지에 넣지 않고 실제 HTML 텍스트로 표시합니다.

| 타일 | 그림 |
| --- | --- |
| 0 | 빨간 카메라 |
| 1 | 데이지 |
| 2 | 파란 커피잔 |
| 3 | 파란 줄무늬 셔츠 |
| 4 | 레코드 |
| 5 | 펼친 책 |
| 6 | 노란 티켓 |
| 7 | 파란 리본 |
| 8 | 접힌 신문 |

웹에서는 CSS 배경 위치로 각 그림을 표시합니다. 내보내기는 같은 시트에서 해당 타일을 지면에 배치합니다.

## 글꼴

원본: [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9), Kil Hyung-jin. 라이선스 원문은 `app/static/fonts/OFL.txt`에 포함했습니다.

- `Pretendard-Regular.woff2`, `Pretendard-Bold.woff2`: 공식 배포 파일을 변경 없이 포함합니다. 웹 화면에 사용합니다.
- `DaynewsSans-Regular.ttf`, `DaynewsSans-Bold.ttf`: PNG·PDF 렌더러를 위한 동일 글리프의 비압축 TrueType 변환본입니다. 글리프 디자인은 바꾸지 않았습니다. OFL의 예약 글꼴 이름 규정에 따라 내부 이름을 **Daynews Sans**로 변경했습니다. 이 변환본 역시 SIL OFL 1.1을 따릅니다.

웹 글꼴도 프로젝트에 들어 있으므로 실행할 때 CDN에 접속할 필요가 없습니다. 본문·제목 모두 산세리프이며 명조체를 사용하지 않습니다.

## 참고

[Digibouquet](https://digibouquet.vercel.app/)의 단계별 선택과 조립 경험을 참고했습니다. 결과는 개인 뉴스·기록 서비스에 맞게 새로 구성했습니다. 16:9는 승인된 데스크톱 시안의 비율이며, 실제 웹 페이지 높이를 16:9로 고정하지 않습니다.
