# 하루신문 · Flask v1

하루 동안 기록을 모으고, 나를 주인공으로 한 신문을 발행하는 개인 다이어리입니다. **API 키 없이 바로 실행되는 데모 모드**와 **OpenAI로 기사를 작성하는 모드**를 제공합니다.

크림색 종이, 블루 리본, 수채화 일러스트와 Pretendard를 사용했습니다. 웹 화면은 반응형이며, 데스크톱 16:9 화면에서도 사용할 수 있습니다. 저장용 스토리 표지는 별도로 9:16입니다.

## 1. 실행하기

Python **3.11 이상**이 필요합니다. ZIP을 풀고 VS Code에서 `daynews` 폴더를 열어주세요. 아래 명령은 `run.py`가 있는 폴더의 터미널에서 실행합니다.

### Windows · PowerShell

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

`py` 명령이 없다면 첫 줄의 `py -3`를 `python`으로 바꿉니다. 가상환경을 활성화하지 않고 실행하므로 PowerShell 실행 정책을 바꿀 필요가 없습니다.

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

브라우저에서 [하루신문 열기](http://127.0.0.1:5000)에 접속합니다. 첫 설치에 인터넷이 필요하며, 설치 후 데모 모드는 외부 API 없이 동작합니다. 종료는 터미널에서 `Ctrl+C`입니다.

첫 실행 시 `instance/`에 SQLite DB, 업로드 폴더와 세션 서명 키가 자동으로 만들어집니다. DB 초기화 명령이나 별도 DB 서버는 필요하지 않습니다.

### VS Code에서 F5로 실행

Microsoft Python 확장을 설치하고, `Python: Select Interpreter`에서 이 폴더의 `.venv`를 선택합니다. 포함된 실행 구성 **하루신문 Flask**를 선택해 F5를 누르면 됩니다. 위 설치 명령을 먼저 실행해야 합니다.

## 2. 사용 순서

1. **가입 / 로그인**: 아이디, 비밀번호, 기사에 사용할 이름을 등록합니다.
2. **오늘 신문 채우기**: 일상·기분·음식·옷차림·음악·책·문화 중 기록할 주제 카드를 누릅니다.
3. **기록 저장**: 해당 주제의 입력칸을 채웁니다. 사진은 선택이며, 저장하면 발행 대기실로 돌아갑니다. 같은 주제로 여러 번 기록할 수 있습니다.
4. **하루 동안 누적**: 다시 로그인해도 같은 날짜의 기록을 이어서 수정·추가할 수 있습니다. 삭제한 기록은 휴지통에서 복원합니다.
5. **자동 코너 선택**: 별도 구역의 날씨·스포츠·운세·포춘쿠키는 체크만 합니다. `코너 선택 저장`으로 선택을 보관하거나 발행할 때 함께 저장합니다.
6. **하이라이트 선택**: 저장된 기록 중 신문에 넣을 항목을 체크하고, 포함된 항목 하나를 1면 하이라이트로 지정합니다. 포함 여부와 하이라이트는 발행 직전에 선택합니다.
7. **신문 발행**: 기록을 기사로 바꾸고, 리본이 풀리며 신문이 펼쳐집니다. 성공한 발행본은 보관함에 자동 저장됩니다.
8. **수정 / 내보내기**: 기사 수정은 새 버전으로 저장합니다. PNG, PDF, 기기 공유, 읽기 전용 링크를 사용할 수 있습니다.

오전·점심·저녁의 기록이 같은 날짜에 계속 쌓이는 구조입니다. 알림이나 방문 횟수 보상 기능은 포함하지 않았습니다.

## 3. 결과물은 이렇게 나옵니다

| 위치 | 구성 |
| --- | --- |
| 신문 상단 | 날짜, 신문 이름, 발행 버전 |
| 1면 | 선택한 하이라이트의 큰 제목, 사진 또는 일러스트, 기사 본문 |
| 1면 옆 칸 | 하이라이트에 관한 짧고 장난스러운 단신 |
| 이어지는 지면 | 나머지 기록을 2열 모듈로 배치; 모바일에서는 1열 |
| 작은 코너 | 선택한 날씨·스포츠·운세·포춘쿠키 |

AI는 제목과 본문을 작성하고, Flask/Jinja와 CSS가 레이아웃을 담당합니다. AI가 HTML/CSS를 만들지 않습니다. 기록이 많아지면 아래로 지면이 늘어나며, PDF는 자동으로 페이지를 추가합니다.

**데모 모드**는 사용자 원문을 직접 인용하는 규칙 기반 기사입니다. **AI 모드**는 주제별 기자 페르소나로 제3자 시점의 기사를 작성합니다. 두 모드는 화면과 내보내기에 표시됩니다.

가상 예시 기록으로 실제 출력한 [스토리 표지 PNG](docs/sample-cover.png)와 [전체 신문 PDF](docs/sample-newspaper.pdf)도 포함했습니다. 이 샘플은 가입한 계정의 DB에 자동으로 추가되지 않습니다.

## 4. 실제 AI 연결하기

`python run.py`를 실행하면 터미널에서 OpenAI API 키를 입력할 수 있습니다. 키를 입력하면 AI 모드로, Enter만 누르면 데모 모드로 시작합니다.

입력한 키는 화면에 표시되지 않고 파일에도 저장되지 않으므로 서버를 실행할 때마다 입력합니다. 이 실행 방식에서는 기존 환경 변수나 `.env`의 API 키와 AI 모드 대신 직접 입력한 값을 사용합니다. 모델을 변경하려면 프로젝트의 `.env`에 `OPENAI_MODEL`을 설정하세요.

- 기본 모델은 변경 가능합니다. Chat Completions의 `json_schema` 구조화 출력을 지원하는 모델을 사용합니다.
- 선택한 기록마다 주제별 기자가 기사를 쓰고, 하이라이트는 단신 기자가 한 번 더 작성합니다. 기록 N개 발행 시 AI 요청은 N+1회이며 API 비용이 발생할 수 있습니다.
- API로 보내는 것은 사용자의 기사 속 이름, 주제, 기록 텍스트입니다. **사진은 보내지 않습니다.** 사진은 신문 지면에만 배치합니다.
- 입력에 없는 사건·대화·반응을 만들지 않도록 지시합니다. 생성된 문장은 공유 전에 확인하고 수정할 수 있습니다.
- 키·네트워크·모델 오류가 나면 실패를 표시하고 원본을 보존합니다. 데모 결과로 자동 대체하지 않습니다.
- 내려받기나 과거 발행본 열기는 AI를 다시 호출하지 않습니다. 다시 발행하기는 새 요청입니다.

API 키 없이 기능을 살펴보려면 실행 시 API 키 입력에서 Enter를 누릅니다.

## 5. 자동 코너와 1차 버전 범위

| 코너 | 현재 동작 |
| --- | --- |
| 날씨 | 기본은 미연동 표시. `.env`에서 `WEATHER_ENABLED=true`로 켜면 설정한 도시의 해당 날짜 최저·최고기온 예보를 Open-Meteo에서 조회 |
| 스포츠 | 팀 이름을 표시하고 **미연동**으로 안내. 실제 경기 결과 제공자는 아직 연결하지 않음 |
| 운세 | 날짜에 따른 가벼운 오락용 문구. 생년월일 기반 사주 계산은 미구현 |
| 포춘쿠키 | 날짜에 따른 오락용 문구 제공 |

지역은 설정에서 서울·부산·대구·인천·제주·광주·대전 중 선택합니다. 날씨는 예보 API이므로 오래된 날짜는 조회에 실패할 수 있으며, 이때 `조회 불가`로 표시합니다. 자동 코너의 결과도 발행 시점 그대로 저장됩니다. 외부 데이터가 없을 때 임의의 경기 결과나 기온을 만들지 않습니다.

## 6. 사진과 내보내기

- 사진: 기록당 최대 3장, 장당 10MB, JPEG/PNG/WEBP, 최대 24메가픽셀. 저장 시 회전을 보정하고 긴 변 최대 2,200px의 JPEG로 변환해 메타데이터를 제거합니다. HEIC는 지원하지 않습니다.
- `사진 촬영`은 모바일 브라우저의 파일 입력 기능을 사용합니다. 기기에 따라 카메라 대신 파일 선택기가 뜰 수 있습니다.
- **PNG**: 1080×1920, 1면 요약용 이미지. 제목·본문 일부가 요약되므로 전체 기사를 모두 담는 파일은 아닙니다.
- **PDF**: A4, 1면과 이어지는 다단 지면. 모든 기사와 사진을 포함하고 한글 글꼴을 내장합니다.
- **기기로 공유**: 첫 클릭에 PNG 준비 → 두 번째 클릭에 시스템 공유창. Web Share API가 없으면 이미지 다운로드로 연결합니다. Instagram 특정 화면으로의 직접 전송을 보장하지 않습니다.
- **공유 링크**: 명시적으로 생성한 발행본만 읽기 전용으로 공개합니다. 공유 해제 후 해당 링크는 열리지 않습니다. 기존에 다운로드한 파일까지 회수하지는 않습니다.
- 로컬 주소의 링크는 내 컴퓨터에서만 열립니다. 다른 사람에게 링크를 보내려면 별도 서버 배포가 필요합니다. 이미지·PDF 파일은 로컬 실행 상태에서도 공유할 수 있습니다.

## 8. 데이터 관리와 실행 특성

계정·기록·발행본은 SQLite에 저장됩니다. 계정마다 접근을 구분하며, 날짜는 설정한 시간대를 기준으로 합니다. 시간대 변경이 기존 기록의 날짜를 바꾸지는 않습니다.

발행본은 원본과 별도로 저장합니다. 원본을 수정·삭제해도 이미 발행한 신문은 바뀌지 않습니다. 기사 수정과 재발행은 버전을 추가하며, 공유 링크는 생성 당시 버전에 고정됩니다. 발행 중 원본이 변경되면 해당 작업은 중단됩니다.

`삭제`는 휴지통 이동입니다. 과거 발행본의 사진을 유지하기 위해 사진 파일을 즉시 제거하지 않습니다. 영구 삭제·계정 삭제·비밀번호 재설정 기능은 이번 버전에 포함하지 않았습니다.

이 프로젝트는 **로컬 단일 프로세스 실행용 1차 버전**입니다. SQLite와 프로세스 안의 작업 스레드를 사용합니다. 서버가 중간에 종료되면 진행 중 작업은 다음 시작에서 실패로 표시되며, 기록을 확인한 뒤 다시 발행할 수 있습니다. 운영 배포 시 별도의 작업 큐와 배포 서버 구성이 필요합니다.

백업은 서버를 종료한 뒤 `instance/` 전체를 복사합니다. DB와 `uploads/`를 함께 보관해야 사진도 복구됩니다. `.env`, `instance/secret.key`, DB, 사용자 사진은 Git에 올리지 않도록 제외되어 있습니다.

## 9. 테스트와 문제 해결

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

위 `python`은 생성한 가상환경의 Python을 사용합니다. 가입→기록→발행→내보내기, 다른 계정의 접근 차단, 원본과 발행본 분리, 공유 해제, 중복 발행, 수정 충돌, 긴 한글 PDF, AI 공급자 성공/실패를 검증합니다. AI 공급자 테스트는 모의 응답을 사용하며 유료 API를 호출하지 않습니다.

- **`No module named flask`**: 실행한 Python과 패키지를 설치한 Python이 같은 가상환경인지 확인합니다.
- **5000 포트 사용 중**: `.env`에 `PORT=5001`을 넣고 재시작한 뒤 [5001 포트](http://127.0.0.1:5001)를 엽니다.
- **API 키를 넣었는데 데모로 나옴**: `AI_MODE=openai` 설정과 서버 재시작을 확인합니다.
- **요청 만료 안내**: 로그인한 화면을 새로고침합니다. 서버의 세션 키를 바꾸면 기존 로그인이 만료됩니다.
- **아이폰 사진 업로드 오류**: HEIC 대신 JPEG/PNG로 저장한 사진을 사용합니다.
